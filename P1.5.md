## F — Security hardening (this PR)

Audited in the post-P1 review (see `SECURITY.md` for the full operator
guide). Six high-risk items, all closed here.

| Item | Risk | Fix |
|---|---|---|
| CORS reflection | `Access-Control-Allow-Origin` echoed any caller; credentials on → wide-open XSRF | `internal/gateway/middleware/cors.go` now reads `cfg.CORSAllowedOrigins` whitelist; empty list = no cross-origin. `CORS_ALLOWED_ORIGINS` env |
| SSRF on cover fetch | `fetchRemoteBytes` performed `http.Get` on a frontend-supplied URL — could hit `169.254.169.254`, internal Redis, etc. | New `internal/netguard` package validates scheme + resolved IPs (rejecting loopback/private/link-local/multicast/unspecified). Wired into `handler/update.go::fetchRemoteBytes` |
| Path traversal | `MusicID3`, `UpdateID3`, `BatchUpdateID3` did `fp + "/" + req.FileName` or trusted raw paths | New `internal/utils.SafeJoin(root, p)` enforces containment. All four handlers re-root every user-supplied path under `MUSIC_DIR` |
| yt-dlp param injection | `extra_audio_format` was concatenated unmarshalled → untrusted JSON into `exec.CommandContext` argv; `--exec=` accepted | New `internal/tasks/yt_dlp_validate.go` with `SanitizeYTDLPFormat`, `SanitizeYTDLPOutputFormat`, `SanitizeYTDLPQuality`. Called by both `handler/youtube.go::YoutubeDownload` and `tasks/yt_dl.go::ProcessTask` (defence-in-depth) |
| admin/admin defaults | `loadUsers()` always seeded `admin:admin`; `JWTSecret` defaulted to `"change-me-in-production"` — both silent failures | `config.Load()` now `log.Fatalf`s on placeholder `JWT_SECRET` unless `ALLOW_INSECURE_DEFAULTS=1`. `handler/auth.go::loadUsers` returns empty (fail-closed) for unset `ADMIN_USERS` outside dev mode. `Login/Refresh/Verify` doubly reject when JWTSecret is the placeholder |
| gRPC plaintext | All seven plugin clients dialled with `insecure.NewCredentials()` | `internal/plugin/grpc_adapter.go` now takes `DialOptions{UseTLS, CAFile}`; `cmd/gateway/main.go` and `cmd/worker/main.go` pass them through. `DialOptions.Credentials()` builds TLS creds against system root pool + optional `GRPC_TLS_CA_FILE` PEM bundle |

### New env vars (all unset → fail-closed or warn-loud)

| Env | Default | Behaviour |
|---|---|---|
| `CORS_ALLOWED_ORIGINS` | empty | empty list = browser blocks cross-origin requests; origins comma-separated |
| `GRPC_USE_TLS` | unset (=false) | `=1` switches plugin dials to TLS; warning logged by `config.Load()` if unset + not dev mode |
| `GRPC_TLS_CA_FILE` | empty | PEM CA bundle; only used when `GRPC_USE_TLS=1`; empty = system roots |
| `ALLOW_INSECURE_DEFAULTS` | unset (=false) | Must be `=1` to start with placeholder JWT_SECRET or admin/admin fallback. Production MUST leave this off; ops must ship real `JWT_SECRET`. |
